File name placeholders

{date}2026-11-06
{time}14-30-05
{datetime}2026-11-06_14-30-05
{yyyy} {yy} {MM} {dd}year, short year, month, day
{HH} {mm} {ss}hour, minute, second
{n}running number (1, 2, 3 …)
{n:3}running number with 3 digits (001)
{max} {min} {centre}hottest, coldest, centre temperature (23.4C)
{p1} {p2} …temperature of measurement point 1, 2 …
{palette}colour palette name

Example: Fan_{n:3}_{max} gives Fan_007_41.2C_2026-11-06_14-30-05.png with “Append date and time” switched on. Characters that are not allowed in file names are replaced by _. The running number counts up with every photo downloaded from this browser.
